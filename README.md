# Jonas Odoo Addons

Módulos para Odoo 20.0 Community.

## Módulos

| Módulo | Versión | Descripción |
| ------ | ------- | ----------- |
| [ce_dark_mode](ce_dark_mode/) | 20.0.1.0.0 | Modo oscuro por usuario para el backend (solo Community) |

## Instalación

```bash
git clone -b 20.0 https://github.com/jonasbonilla/jonas-odoo-addons.git
```

Agrega la ruta a `addons_path`, actualiza la lista de apps e instala el módulo.
