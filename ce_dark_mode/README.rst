Per-user dark mode for the Odoo Community backend.

- The preference is stored on the user, not in the browser, so users
  sharing a browser keep their own scheme. The ``color_scheme`` cookie
  is kept in sync from the server and cleared on logout.
- Uses Odoo's native dark bundles (``web.assets_web_dark``,
  ``web.assets_backend_lazy_dark``), so the core ``*.dark.scss`` files
  (mail, calendar, html editor, sale...) apply as they do in Enterprise.
- Real dark palette, aligned with Odoo Enterprise's dark mode, plus
  component fixes (buttons, statusbar, kanban, dropdowns, alerts,
  settings, spreadsheet dashboards...). It is not a CSS color inversion.

Community only: Enterprise ships its own dark mode, so this module
cannot be installed together with ``web_enterprise``.

Usage
=====

Each user can switch the scheme in two ways:

- **User menu** (avatar, top right): toggle **Dark Mode**. The page
  reloads with the new scheme.
- **My Profile / Preferences**: set **Color Scheme** to *Light* or
  *Dark*, save, and reload the page.

Administrators can also set it for any internal user from *Settings >
Users*.
